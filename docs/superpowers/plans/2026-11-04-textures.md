# Textures Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let callers upload RGBA8 textures and draw each scene object sampled from its own texture, combined with per-vertex color.

**Architecture:** Textures are renderer-owned GPU resources referenced by a `Copy` `TextureId` handle; the renderer frees them on `Drop`. The camera UBO stays at descriptor set 0; a per-object combined-image-sampler is bound at set 1. `Object { model, texture: Option<TextureId> }` is the single draw unit; `None` samples a 1×1 white default so untextured objects look exactly as before. The existing sampled-image/upload path (built for the font atlas) is generalized rather than forked.

**Tech Stack:** Rust, `ash` (Vulkan 1.3), `gpu-allocator`, `bytemuck`, `m2s2-math`; GLSL compiled offline with `glslc`, SPIR-V committed.

**Spec:** `specs/010-textures.md`

## Global Constraints

- Vulkan **1.3** required (spec 009); dynamic rendering is core. Do not reintroduce extension loaders.
- Matrices are **row-major** (`m2s2-math`); GLSL uniform/push blocks already declare `row_major`.
- Textures use **`R8G8B8A8_SRGB`**; the swapchain is already sRGB.
- Camera at **descriptor set 0**; per-object texture at **descriptor set 1, binding 0**, `COMBINED_IMAGE_SAMPLER`, fragment stage.
- **No new crate dependencies.** No image-file decoding in this crate (caller supplies raw RGBA8).
- **No mipmaps** (single mip level); linear filter for textures, `CLAMP_TO_EDGE`. The font keeps nearest.
- Quality gates must pass with **zero warnings**: `cargo fmt --all -- --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo build --all-targets`, `cargo test --all-targets`.
- Commit subjects follow **Conventional Commits**. **No `Co-Authored-By` / AI-attribution trailer** in any commit.
- Shader edits are compiled offline and the `.spv` committed: `glslc shaders/triangle.vert -o shaders/triangle.vert.spv` (and `.frag`), then `spirv-val` each.

## Review Focus

- **`create_texture` with `rgba8.len() != width*height*4`, or a zero dimension** → `VulkanError::ValidationError` returned before any GPU work, not a panic. *(Test in Task 2, `validate_pixels` 4-bpp cases.)*
- **`Object.texture = Some(id)` whose index is out of range** (a stale handle, or one from a different renderer) → resolves to the white texture rather than panicking on an out-of-bounds index. *(Test in Task 2, `resolve_texture_set`.)*
- **Empty `&[Object]`** → frame still clears and presents with no object draws. *(Test in Task 2, `emit_object_draws` empty case.)*
- **A frame mixing `Some` and `None` objects** → each object binds the correct set-1 descriptor, in submission order. *(Test in Task 2, `emit_object_draws` ordering case.)*
- **`create_texture` GPU allocation failure** → returns `Err`, the texture store is unchanged, and no partial resource leaks. *Structural guarantee, not a CI test (no way to inject a driver failure without a GPU): `StoredTexture::new` fully rolls back its own partial resources on error, and `create_texture` pushes to the store only after `StoredTexture::new` returns `Ok`. Verified behaviorally by the GPU run in Task 3.*

```rust
    error::{Result, VulkanError},
    math::Mat4,

use ash::vk;

/// Opaque handle to a renderer-owned texture (an index into the renderer's texture store).
/// `Copy`; valid for the lifetime of the renderer that produced it.
#[derive(Copy, Clone, PartialEq, Eq, Debug)]
pub struct TextureId(pub(super) usize);

/// One drawn copy of the uploaded mesh. `texture: None` samples the renderer's 1x1 white default,
/// so an untextured object reproduces the pre-texture look (`white * vertexColor == vertexColor`).
pub struct Object {
    pub model: Mat4,
    pub texture: Option<TextureId>,
}

/// The descriptor set bound at set 1 for an object: the stored texture's set, or `white` when the
/// object has no texture or references an out-of-range handle (a stale/foreign id falls back to
/// white rather than indexing out of bounds).
pub(super) fn resolve_texture_set(
    texture: Option<TextureId>,
    texture_sets: &[vk::DescriptorSet],
    white: vk::DescriptorSet,
) -> vk::DescriptorSet {
    match texture {
        None => white,
        Some(TextureId(index)) => texture_sets.get(index).copied().unwrap_or(white),
    }
}
```

In `src/renderer/texture.rs`, add the GPU-backed resource and layout helper (model the descriptor code on `text.rs`'s font descriptor):

```rust
const TEXTURE_BINDING: u32 = 0;

pub(super) fn create_set_layout(device: &VulkanDevice) -> Result<vk::DescriptorSetLayout> {
    let bindings = [vk::DescriptorSetLayoutBinding::default()
        .binding(TEXTURE_BINDING)
        .descriptor_type(vk::DescriptorType::COMBINED_IMAGE_SAMPLER)
        .descriptor_count(1)
        .stage_flags(vk::ShaderStageFlags::FRAGMENT)];
    unsafe {
        device
            .device
            .create_descriptor_set_layout(&vk::DescriptorSetLayoutCreateInfo::default().bindings(&bindings), None)
    }
    .map_err(crate::error::VulkanError::from)
}

pub(super) struct StoredTexture {
    image: SampledImage,
    pool: vk::DescriptorPool,
    pub(super) set: vk::DescriptorSet,
}

impl StoredTexture {
    pub(super) fn new(
        device: &VulkanDevice,
        allocator: &mut Allocator,
        layout: vk::DescriptorSetLayout,
        rgba8: &[u8],
        width: u32,
        height: u32,
    ) -> Result<Self> {
        // SampledImage::new_rgba8_srgb validates and rolls back its own partial resources on error.
        let mut image =
            SampledImage::new_rgba8_srgb(device, allocator, vk::Extent2D { width, height }, rgba8)?;
        let dev = &device.device;
        // Allocate the descriptor pool/set after the image. On any error here the image is already
        // owned, so destroy it before returning so nothing leaks.
        let result = (|| {
            let sizes = [vk::DescriptorPoolSize::default()
                .ty(vk::DescriptorType::COMBINED_IMAGE_SAMPLER)
                .descriptor_count(1)];
            let pool = unsafe {
                dev.create_descriptor_pool(
                    &vk::DescriptorPoolCreateInfo::default()
                        .max_sets(1)
                        .pool_sizes(&sizes),
                    None,
                )
            }
            .map_err(VulkanError::from)?;
            let set = unsafe {
                dev.allocate_descriptor_sets(
                    &vk::DescriptorSetAllocateInfo::default()
                        .descriptor_pool(pool)
                        .set_layouts(&[layout]),
                )
            }
            .map_err(VulkanError::from)?[0];
            let info = [vk::DescriptorImageInfo::default()
                .image_view(image.view)
                .sampler(image.sampler)
                .image_layout(vk::ImageLayout::SHADER_READ_ONLY_OPTIMAL)];
            unsafe {
                dev.update_descriptor_sets(
                    &[vk::WriteDescriptorSet::default()
                        .dst_set(set)
                        .dst_binding(TEXTURE_BINDING)
                        .descriptor_type(vk::DescriptorType::COMBINED_IMAGE_SAMPLER)
                        .image_info(&info)],
                    &[],
                )
            };
            Ok((pool, set))
        })();
        match result {
            Ok((pool, set)) => Ok(Self { image, pool, set }),
            Err(error) => {
                image.destroy(device, allocator);
                Err(error)
            }
        }
    }

    pub(super) fn destroy(&mut self, device: &VulkanDevice, allocator: &mut Allocator) {
        unsafe { device.device.destroy_descriptor_pool(self.pool, None) };
        self.image.destroy(device, allocator);
    }
```

- [ ] **Step 1: Implement `create_texture`**

In `src/renderer/mod.rs`, add to the `impl VulkanRenderer` block:

```rust
    /// Upload an RGBA8 image (`rgba8.len() == width * height * 4`, both non-zero) into a new
    /// renderer-owned texture, returning its handle. The texture is freed when the renderer drops.
    pub fn create_texture(&mut self, rgba8: &[u8], width: u32, height: u32) -> Result<TextureId> {
        let stored = StoredTexture::new(
            &self.device,
            &mut self.allocator,
            self.texture_set_layout,
            rgba8,
            width,
            height,
        )?;
        let id = TextureId(self.textures.len());
        self.texture_sets.push(stored.set);
        self.textures.push(stored);
        Ok(id)
    }
```

(Note the ordering: `texture_sets` and `textures` grow only after `StoredTexture::new` returns `Ok`, so a failed upload leaves the store unchanged — the Review Focus allocation-failure guarantee. `TextureId` is `pub(super)`-constructed here within the crate.)
